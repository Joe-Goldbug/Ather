## 1. 项目定位基准回顾

当前项目定义以 [项目定位](PROJECT-POSITIONING.md) 为准。以下竞品研究和产品建议不自动构成已确认需求。
* **核心使命**：**IA（Intelligence Augmentation，增强人类智能）**。通过 AI 引导的互动体验，帮助用户理解自己的思考模式、了解自身人格性格。
* **产品形态**：计算化心智镜像（Computational Mind Mirror）与动态自我模型（Self OS）。
* **四大坚决非目标**：
  1. ❌ 非临床心理诊疗/医疗处方；
  2. ❌ 非 MBTI/九型人格式伪科学一次性打标签；
  3. ❌ 非泛娱乐陪伴、赛博恋人或无目的闲聊 Bot；
  4. ❌ 非空气代币投机、数据买卖或剥削式金融化庞氏。

## 3. 潜在用户核心诉求与行业四大致命硬伤

通过对反思类应用、Reddit 理性主义社区（r/Rationality、r/Productivity）及 Web3 数据主权讨论的综合调研，当前用户面临以下未被满足的痛点：

### 3.1 硬伤一：AI 极度“迎合讨好”(Sycophancy)，缺乏真正的镜像纠偏力
* **现状分析**：主流大模型经过 RLHF（基于人类反馈的强化学习）微调后，普遍患有“讨好型人格”。用户提出了一个漏洞百出甚至冲动的抉择，AI 的第一反应通常是：“*这是一个非常深思熟虑且有前瞻性的想法！我完全理解你的处境……*”
* **用户真实渴望**：严肃的知识工作者和创业者，在现实中往往不缺朋友的安慰，**唯独缺乏冷酷、清醒、不讲情面的“红队审查（Red Teaming）”**。他们需要 AI 像一面不修饰瑕疵的镜子，直接指出：“*你在第一步假设了对方一定会妥协，但你的证据链完全缺失。如果对方拒绝，你的备选方案是什么？*”

### 3.2 硬伤二：有决策无复盘，缺少时间维度的“事后检验”(Post-Mortem) 闭环
* **现状分析**：市面上的工具几乎都是“一次性体验”。做完一次心智测试或完成一篇日记后，流程便彻底终结。用户现实中的决策是否正确、三个月后事情如何发展，没有任何跟踪。
* **用户真实渴望**：**未经验证的思考不是真正的决策。** 用户需要一个长效闭环：
  1. 记录决断当下的逻辑依据、预期结果与信心打分；
  2. 在现实时间点（如 14 天、30 天后）自动唤醒回顾；
  3. 现实对照：当初预判对了什么？错在哪里？系统沉淀出用户的真实认知偏好演化（“You Shifted”）。

### 3.3 硬伤三：“被审问感”(Feeling Interviewed) 与空白页启动阻力
* **现状分析**：许多反思工具（如常规 AI Journaling）一上来就给空白输入框，或者抛出抽象的大问题（“你今天有什么反思？”、“如何看待你的人际关系？”）。用户产生极强的认知负荷与心理防御，感觉像在接受 HR 考核或写命题作文。
* **用户真实渴望**：**沉浸式的微情境引导。** Eva 现有的《雨停之前》剧本抉择是极其正确的路线——通过具体、真实的两难情境（涉及信任、利益、冲突的抉择），让用户自然流露潜意识防御取向，而非逼其自我剖白。

### 3.4 硬伤四：深层心智隐私焦虑，用户不敢在云端说真心话
* **现状分析**：把最深沉的心理弱点、职场真实利益算计、合伙人分歧输入中心化 Web2 平台时，用户有本能的恐惧（担心被云端日志捕获、担心被拿去训练下一代通用模型）。
* **用户真实渴望**：
  * **主权控制**：本地/隔离存储，平台拥有不可突破的行级安全隔离（RLS）；
  * **绝对不上链**：原文对话哪怕加密也绝不上公链；
  * **证明与内容解耦**：链上只存单向 Hash 作为防伪时间锚点，脱敏凭证供自我备忘或选择性出示。

## 4. Eva 下一阶段产品功能迭代蓝图

基于上述洞察，Eva 下一步的迭代应当聚焦于**强化认知利刃、闭环时间复盘、极简隐私证明**三大维度：

```
                    ┌──────────────────────────────────────────────┐
                    │            Eva 认知增强操作系统 (Self OS)      │
                    └──────────────────────┬───────────────────────┘
                                           │
         ┌─────────────────────────────────┼─────────────────────────────────┐
         ▼                                 ▼                                 ▼
┌──────────────────┐             ┌──────────────────┐             ┌──────────────────┐
│  苏格拉底红队推演室 │             │   决策时间胶囊与   │             │   脱敏认知指纹卡   │
│ (Red Teaming)    │             │   事后复盘链     │             │ (EAS/SBT 凭证)   │
│                  │             │  (Post-Mortem)   │             │                  │
│ • 事实 vs 假设分离 │             │ • 冻结初始假设与信心 │             │ • 零明文数据上链   │
│ • 寻找唯一推翻条件 │             │ • 30天后唤醒复盘  │             │ • 心智平衡度雷达图 │
│ • 拒绝 AI 讨好迎合│             │ • 追踪认知演变轨迹 │             │ • 链上可核验证明   │
└──────────────────┘             └──────────────────┘             └──────────────────┘
```

### 4.1 功能一：苏格拉底“红队推演室”(Decision Red Teaming)
* **功能描述**：专门针对用户在现实中面临的重大两难抉择（如：业务转型、合伙人去留、高风险投资、团队冲突）。
* **交互流程（5 步认知审查）**：
  1. **输入命题**：用户简述问题及目前倾向的决定；
  2. **区分事实与假设**：Eva 逐句提问，强制用户将“已经发生的事实”与“自己脑补的推论”拆分；
  3. **寻找唯一推翻条件（Killing Condition）**：要求用户回答：“发生什么具体情况时，你必须立刻承认当前的决定彻底错了？”；
  4. **反对派辩论**：Eva 模拟 2 个最强烈的反对派论点，进行压力测试；
  5. **生成决策校准备忘**：用户重新衡量信心分数（1~10 分），输出结构化决策档案。

### 4.2 功能二：决策时间胶囊与复盘链 (Decision Post-Mortem Loop)
* **功能描述**：打通“思考 → 行动 → 现实结果检验”的全链路。
* **业务逻辑**：
  * **时间封存**：决策备忘生成后，系统为该决策生成防篡改指纹（HMAC 或可选的 Base 链上 EAS 声明），锁定当时的时间戳与预测内容。
  * **定时敲门**：到期（如用户自定义的 14/30/90 天后），Eva 通过推送或邮件提醒：“*30 天前你决定进行团队拆分，预期的关键指标达成了吗？*”
  * **心智漂移检测（You Shifted）**：对照记录当下的实际偏差，沉淀到用户的“长期认知档案”中，直观展示用户是在高估收益、忽视人际阻力，还是在关键数据上产生盲点。

### 4.3 功能三：行业情境微剧本生成器 (Micro-Scenario Dilemma Generator)
* **功能描述**：扩展单一的《雨停之前》，提供多样化的高压情境剧本。
* **剧本矩阵规划**：
  * **情境 A：《最后一笔过桥贷款》**（面向创业与商业场景：在现金流断裂、道德红线与团队生存之间的极端抉择）；
  * **情境 B：《合伙人的抽屉》**（面向核心协作场景：面对利益分配不对称与信任裂痕时的防御机制检测）；
  * **情境 C：《暴风雨中的灯塔》**（面向个人关键生涯选择：安全感与自我实现的边界博弈）。
* **设计标准**：每个剧本保持 5~6 个紧凑决策节点，耗时控制在 5 分钟内，低阻力映射出用户的核心认知偏好。

### 4.4 功能四：脱敏 EAS 认知指纹卡 (Verifiable Mind Fingerprint)
* **功能描述**：满足用户的自我表达与社交分享诉求，同时捍卫绝对隐私。
* **展现形态**：
  * 一张具备极高美学水准的手绘赛博风格卡片：
    * 4 维认知平衡度雷达图（直面度、防御度、分析度、抽离度）；
    * 提炼出核心认知特征评语（如：“*具备罕见的冷静结构拆解力，但在面对非理性冲突时存在过早防御倾向*”）；
    * 底部附带 Base 链上 EAS 证明 UID 与二维码，任何第三方均可查验该卡片的防伪哈希与生成时间。
  * **传播效应**：适合用户分享至 Twitter/X、即刻或 LinkedIn，展现深度思辨力与独特性，形成自然的社区裂变。

### 4.5 机制优化：降低经济与技术准入门槛 (去除早期 Vault 摩擦)
* **优化策略**：
  * **严禁强买 RWA**：坚决避免“要求用户先质押 200~500 美元 USDC 购买生息资产才能体验”的设计。
  * **纯无感 Web3 底座**：
    * 前端采用 Coinbase Smart Wallet（Passkey 指纹/Face ID 直接创建链上身份，告别助记词）；
    * 链上交互由官方 Paymaster 全额代付 Gas 费（单次仅约 $0.002）；
  * **商业化闭环演进**：
    * 第一阶段：提供每日/每周基础免费推演额度，建立高粘性与口碑；
    * 第二阶段：高频/重度用户采用标准 Web2 订阅（Stripe）；
    * 第三阶段：待模型本地化成本极大压缩、且合规资质完全完备后，再将 Compute Vault 作为高净值 Web3 极客的“可选利息抵扣”辅助渠道。

## 5. 落地演进路线与验证指标

| 阶段 | 核心任务 | 交付物 | 核心验证指标 |
| :--- | :--- | :--- | :--- |
| **Milestone 1**<br>(体验打磨与去迎合) | 上线“苏格拉底红队”决策推演原型，调整 Prompt 漏斗抑制大模型讨好倾向 | `Decision Red Teaming` 对话模块 | 真实用户决策推演完成率 > 65%；用户反馈中“提出盲点”的有效度认可率 > 80% |
| **Milestone 2**<br>(时间复盘与剧本扩展) | 引入到期唤醒通知、现实结果对比，上线第二个行业两难剧本 | 邮件/推送定时唤醒系统 + 《最后一笔过桥贷款》剧本 | 30 天唤醒复盘填报率 > 30%；剧本完成时间保持在 5 分钟以内 |
| **Milestone 3**<br>(无感凭证与主权存证) | 接入 Base L2 + EAS 架构，支持一键生成脱敏手绘认知卡片与链上时间戳 | Passkey 钱包集成 + EAS 认证 Schema 部署 | 凭证生成率 > 40%；社交平台分享卡片自发裂变率 |

---

> **结论总结**：Eva 的破局点不在于成为又一个平庸的聊天 Bot 或发币炒作项目，而在于成为**“全球首个拒绝讨好用户、致力于用密码学与科学认知工具守护个人思考质量的 IA 镜像”**。通过红队推演、事后复盘和隐私指纹，Eva 将建立起极深的心智护城河。
