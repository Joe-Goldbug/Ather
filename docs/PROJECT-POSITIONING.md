# Eva 项目定位 / Eva Project Positioning

更新日期 / Updated: 2026-10-07

**中文**：Eva 是一个增强人类智能（IA）的平台，通过 AI 引导的互动体验，帮助用户理解自己的思考模式、了解用户自身人格性格，其 Web3 方向通过可验证凭证与用户自主授权分享，让用户更好地掌控自己的认知记录。

**English**: Eva is an intelligence augmentation (IA) platform that uses AI-guided interactive experiences to help users understand their thinking patterns and explore their personality traits. Its Web3 direction uses verifiable credentials and user-authorized sharing to give users greater control over their cognitive records.

## 产品范围 / Product Scope

通过 AI 引导的互动体验理解思考模式、探索自身人格性格；Web3 方向服务于认知记录的可验证凭证及用户自主授权分享。 / AI-guided interactive experiences support understanding thinking patterns and exploring personality traits; the Web3 direction supports verifiable credentials for cognitive records and user-authorized sharing.

这是项目定位，不是对所有功能已经上线或人格分析已获科学验证的声明。具体实现与验证状态应依据代码和实际验收记录说明。 / This describes the project direction; it does not claim that every feature is live or that personality analysis has been scientifically validated. Implementation and validation status must be supported by code and acceptance evidence.
