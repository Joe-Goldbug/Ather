# Eva 首阶段链选择：Base

决策日期：2026-10-09。状态：**已确认**。本文件替代此前尚未选链的讨论和基于未核实费率、用户规模或 RWA 生态的比较结论。

## 决策

Eva 的首阶段 Web3 目标链确定为 **Base**。开发、Demo 与链路验收使用 **Base Sepolia（chain ID 84532）**；真实用户主网功能在合约、隐私、密钥和运行保障验收通过后再评估启用。这个决定适用于 Eva 当前首阶段，不构成未来永不扩链的承诺。

## 选择依据

- Eva 当前 Web 与 API 采用 TypeScript；Base 是 EVM 链，现有 Viem、EIP-712 代码路径可以复用。
- 当前仓库已经形成 Base 配置、钱包挑战/绑定接口、凭证接口和异步锚定处理框架。统一首阶段网络，便于围绕一个链环境做端到端验证。
- Eva 的核心是 IA 互动与用户控制的记录。Base 只承载需要公开核验的最小承诺/状态；互动、模型推理和私密原始记录继续在链下。
- 当前选择不依赖某个钱包、代币、收益产品或对 Coinbase 产品的背书。用户日常体验不要求先连接钱包。

## 网络与实现边界

| 项目 | 当前决定/事实 |
|---|---|
| 首阶段链 | Base |
| 开发与 Demo 网络 | Base Sepolia，chain ID 84532 |
| 主网 | Base；部署前须单独完成安全、隐私、密钥、费用、运维和用户体验验收 |
| 当前代码默认 RPC | `https://sepolia.base.org` |
| 当前锚定合约地址 | 默认零地址；尚无可用合约地址配置 |
| 钱包与签名 | 已有 EIP-712 challenge、钱包绑定/解绑接口与 Viem 校验代码；运行及部署行为需单独验收 |
| 凭证 | 已有 Ed25519 记录凭证签发、导出、核验及撤销代码；密钥默认缺失时会临时生成，不能据此作为稳定生产签发密钥 |
| 链上提交 | Worker/状态代码存在；`submitCredentialAnchor` 当前生成占位交易哈希，不向真实 Base 合约广播 |

## 进入 Base 主网前的门槛

1. 部署并独立审阅最小化锚定合约，配置并验证真实合约地址与网络 ID。
2. 用隔离测试数据验收真实 Base Sepolia 交易、区块浏览器记录、确认状态、重复请求、失败恢复与队列幂等。
3. 持久化并保护凭证私钥，定义签发者身份、备份、轮换、撤销及事故处置。
4. 确保上链内容为最小化、经用户确认的承诺或状态；禁止原始对话、完整画像、邮箱和敏感记录上链。说明哈希不是加密，地址与时间也可能关联用户。
5. 说明钱包可选、交易费用承担方式、失败与重试体验；不把钱包或交易作为 IA 互动的前置条件。
6. 完成代码审查、安全审查、隐私审查和真实用户验收；当前源码存在不等于部署完成。

## 当前不包含的决策

本次确定的是首阶段网络。它不批准发行 Token/ICO、RWA 金库、生息资产、收益或保本承诺，也不证明凭证中的心理观察准确。是否引入这些功能必须基于独立的用户需求、法律权利、资金与运营条件重新评估。
