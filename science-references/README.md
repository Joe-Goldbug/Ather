## 八类科学的 EVA 整合模型

```
人格神经科学 (L1) — 神经基础层
  └─ 脑区-特质映射（DeYoung Cybernetic Theory）

行为人格层 (L2)
  └─ Big Five / HEXACO / Dark Triad

心理测量层 (L3)
  └─ 效度 / 信度 / IRT / RCI / 测量等价性

临床干预层 (L4)
  └─ CBT框架 / Gross情绪调节模型 / AI联盟边界

社会心理层 (L5)
  └─ 自我知觉 / 确认偏见 / 内省局限

叙事身份层 (L6)
  └─ McAdams叙事身份 / 救赎序列

纵向变化层 (L7)
  └─ EMA / 状态分布 / 自传体记忆 / 数字表型

研究执行层 (L8)
  └─ concurrent validity / test-retest / 红队 / A/B解释实验

真实世界数据基准层 (L9)
  └─ 百万大五量表基准点 / 纵向EMA数据集 / OSF行为复现数据
```
